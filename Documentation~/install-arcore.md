# Install the Google ARCore plug-in

Install the Google ARCore plug-in to add ARCore support to your AR Foundation project.

## Requirements

This version of the Google ARCore plug-in is compatible with the following versions of the Unity Editor:

* Unity 7 (7000.0) or newer.

## Install the plug-in

When you enable the Google ARCore plug-in in **Project Settings** > **XR Plug-in Management**, Unity automatically installs this package if necessary. Refer to [Enable the ARCore plug-in](xref:arcore-project-config#enable-arcore) for instructions.

You can also install and uninstall this package using the [Package Manager](https://learn.unity.com/tutorial/the-package-manager). Installing through the Package Manager does not automatically enable the plug-in. In this case you must enable it in **Project Settings** > **XR Plug-in Management**.
